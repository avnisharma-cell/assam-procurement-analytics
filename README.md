# Assam Government Procurement Analytics

A data analytics project examining six years (FY 2016–17 to 2021–22) of public procurement tenders published by the Government of Assam — where the money went, how competitive the bidding was, and where spending is most concentrated.

Built end-to-end with Python, SQL, and Jupyter — no machine learning, no predictive modelling, no external APIs. Just clean data engineering and honest analysis.

## Key findings

- **Spending is growing per contract, not per tender.** Tender *volume* peaked in FY 2018–19 (9,043 tenders), but total *value* peaked two years later in FY 2020–21 (₹37,418 Cr) on fewer tenders — the average tender size roughly doubled.
- **Two departments dominate spending.** Public Works Roads Department and Public Works Building and NH Department together account for roughly half of all tender value across 101 buyer departments.
- **Weak competition isn't rare.** Around 28% of total tender value went to contracts with either zero or exactly one bidder.
- **Most procurement is genuinely competitive.** ~95% of value goes through standard Open Tender, another ~5% through Global (international) Tenders. Restrictive routes (Limited, Single-source, Auction) account for well under 1% of value — small in share, but real money worth closer scrutiny.
- **Spending is highly concentrated.** The top 1% of tenders by value (~327 contracts out of 34,232) account for 43% of all money spent.

Full analysis, SQL queries, and charts are in [`notebooks/03_core_analysis.ipynb`](notebooks/03_core_analysis.ipynb); a polished, non-technical summary is in [`notebooks/04_visualisation_summary.ipynb`](notebooks/04_visualisation_summary.ipynb).

## Tech stack

- **Python** (pandas, matplotlib, seaborn)
- **SQLite** (`sqlite3`) — all analysis queries are written as real SQL, not pandas standing in for SQL
- **Jupyter Notebook**

No ML, no AI, no external APIs — descriptive analytics only.

## Data source

Assam Finance Department procurement records, via [data.gov.in](https://data.gov.in). 34,232 tenders published by 101 government departments, FY 2016–17 through FY 2021–22.

## Project structure

```
assam-procurement-analytics/
├── data/
│   ├── raw/                          # Source CSVs (gitignored)
│   └── processed/
│       └── tenders_clean.csv         # Cleaned dataset (gitignored)
├── db/
│   └── assam_procurement.db          # SQLite database (gitignored)
├── notebooks/
│   ├── 01_data_loading.ipynb         # Load raw CSVs into SQLite
│   ├── 02_data_cleaning.ipynb        # Clean and standardise the data
│   ├── 03_core_analysis.ipynb        # 5 SQL-driven analyses with charts
│   └── 04_visualisation_summary.ipynb # Polished, presentation-ready dashboard

```

`data/raw/`, `data/processed/`, and `db/` are gitignored — they're generated by running the notebooks, not stored in version control.

## How to run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Place the raw CSVs in `data/raw/` (`main.csv` and `tender_milestones.csv` are required; `tender_documents.csv` and `tender_participationFee.csv` are present in the source data but unused).
3. Run the notebooks **in order** — each one builds on the SQLite tables created by the last:
   1. `01_data_loading.ipynb` — loads the raw data into `db/assam_procurement.db`
   2. `02_data_cleaning.ipynb` — cleans it into a `tenders_clean` table and CSV
   3. `03_core_analysis.ipynb` — runs the analysis
   4. `04_visualisation_summary.ipynb` — the presentation-ready summary
